## Font outline data

`packages/document/src/features/font-data.ts` is generated by `tools/extract-fonts.mjs`
and contains printable-ASCII glyph outlines extracted from the fonts below. It is
redistributed under each font's own licence. Regenerate it with:

```bash
node tools/extract-fonts.mjs
```

| Face in CARDstock | Font | Licence |
|---|---|---|
| Sans | DejaVu Sans | Bitstream Vera Fonts Copyright / DejaVu changes — permissive, redistribution allowed |
| Serif | DejaVu Serif | as above |
| Mono | DejaVu Sans Mono | as above |
| Condensed | DejaVu Sans Condensed | as above |
| Round | Ubuntu Regular | Ubuntu Font Licence 1.0 |

The DejaVu fonts derive from Bitstream Vera, whose licence permits redistribution and
modification provided the fonts are not sold by themselves and the reserved names
"Bitstream" and "Vera" are not used in derivative names. The Ubuntu Font Licence permits
redistribution and modification on equivalent terms. Neither font is shipped as a font
file; only the outline coordinates the Text feature needs to build geometry.
